# راه‌اندازی روی سرور GPU (راهنمای گام‌به‌گام)

این راهنما نشان می‌دهد چطور کل سیستم را روی یک سرور GPU با یک دستور راه‌اندازی
کنید. اسکریپت `gpu/setup_and_run.sh` همه‌ی کارها را خودکار انجام می‌دهد.

## پیش‌نیاز سرور

- سیستم‌عامل Linux با کارت NVIDIA
- **CUDA toolkit** نصب‌شده (یعنی دستور `nvcc` کار کند). اگر فقط `nvidia-smi`
  دارید و `nvcc` نیست، از یک ایمیج داکر با پسوند `-devel` استفاده کنید، مثل:
  `nvidia/cuda:12.4.1-devel-ubuntu22.04`
- دسترسی اینترنت (برای کلون مخزن و اتصال به RPC رابین‌هود)

## اجرای یک‌خطی (حالت آزمایشی، بدون ارسال و بدون هزینه)

روی سرور، این دستورها را وارد کنید:

```bash
git clone https://github.com/0xRadikal/Hash-Cats-Fun.git ~/hashcats
cd ~/hashcats/gpu
bash setup_and_run.sh
```

اسکریپت به‌ترتیب:
1. پیش‌نیازها را نصب می‌کند (git، build tools، کتابخانه‌های پایتون)
2. معماری GPU را تشخیص و کرنل CUDA را کامپایل می‌کند
3. **تست درستی** را اجرا می‌کند (باید همه PASS شود؛ اگر نه، متوقف می‌شود)
4. نرخ هش GPU را نشان می‌دهد
5. ماینر مداوم را در حالت **آزمایشی** اجرا می‌کند (چیزی نمی‌فرستد)

## اجرای واقعی (ارسال تراکنش mint)

⚠️ فقط وقتی که والت شارژ شده باشد و آماده‌ی خرج ~۰.۰۲ ETH + گس باشید.

```bash
cd ~/hashcats/gpu
export HASHCATS_PK=0xکلید_خصوصی_والت_شما      # کلید خصوصی؛ هرگز جایی کامیت نشود
export HASHCATS_MODE=send                      # حالت ارسال واقعی
bash setup_and_run.sh
```

- کلید خصوصی فقط در فایل محلی `~/hashcats/wallet.env` نوشته می‌شود (در
  `.gitignore` است و هرگز کامیت نمی‌شود).
- هر ارسال، ابتدا با `eth_call` شبیه‌سازی می‌شود؛ اگر برنگردد، فرستاده نمی‌شود.
- تراکنش با کارمزد گس کمی بالاتر از رقبا فرستاده می‌شود تا زودتر در بلاک بنشیند.
- به‌محض گرفتن یک گربه، برنامه پیام موفقیت می‌دهد و متوقف می‌شود.

## اجرای پایدار در پس‌زمینه (توصیه‌شده برای اجرای طولانی)

چون ممکن است ساعت‌ها طول بکشد، بهتر است در `screen` یا `tmux` اجرا شود تا با
قطع‌شدن SSH متوقف نشود:

```bash
apt-get install -y screen
screen -S cats
export HASHCATS_PK=0x...   ; export HASHCATS_MODE=send
bash ~/hashcats/gpu/setup_and_run.sh
# برای خروج از screen بدون توقف: Ctrl+A سپس D
# برای بازگشت: screen -r cats
```

## شانس واقع‌بینانه

قدرت کل شبکه‌ی رقبا حدود ۱۰٬۰۰۰ تا ۳۵٬۰۰۰ GH/s است و بین چند نهنگ تقسیم شده.
سهم ما = `نرخ ما / (نرخ شبکه + نرخ ما)`. با یک GPU معمولی این سهم بسیار کوچک
است (کسری از درصد)؛ یعنی شانس گرفتن یک گربه کم ولی **صفر نیست** — همان
«یک در هزار». برای شانس جدی‌تر باید چند GPU قوی داشت.

## عیب‌یابی

| مشکل | راه‌حل |
|------|--------|
| `nvcc not found` | ایمیج CUDA `-devel` استفاده کنید |
| `verify_kernel ... FAIL` | ماین نکنید؛ مشکل ساخت است، گزارش دهید |
| `NOT FUNDED` | والت را شارژ کنید (~۰.۰۲ ETH روی Robinhood Chain) |
| اتصال RPC کند | اسکریپت خودکار به RPC پشتیبان سوییچ می‌کند |
