# ماینر GPU (CUDA) برای Hashcats

این پوشه یک ماینر Keccak-256 روی GPU با زبان CUDA است که درستی آن **بایت‌به‌بایت
با قرارداد Hashcats** تطبیق داده شده است. برخلاف ماینر CPU، این نسخه می‌تواند
میلیاردها هش در ثانیه بزند و سهم واقعی از قدرت شبکه بگیرد.

## چه چیزی در این پوشه است

| فایل | کاربرد |
|------|--------|
| `keccak_cuda.cu` | کرنل اصلی ماینر (هر thread یک nonce را هش می‌کند) |
| `verify_kernel.cu` | صحت‌سنجی خروجی GPU با بردارهای تأییدشده‌ی قرارداد |
| `verify_kernel_cpu.c` | نسخه‌ی CPU همان منطق keccak برای اثبات درستی بدون GPU |
| `test_vectors.json` | جفت‌های `nonce → workHash` که مستقیم از قرارداد گرفته شده‌اند |
| `gpu_hunter.py` | کنترلر ساده (انتظار پنجره، سپس ماین) |
| `gpu_hunter_continuous.py` | کنترلر ماینینگ **مداوم** (توصیه‌شده) |
| `bootstrap.sh` | نصب و کامپایل و تست خودکار روی دستگاه GPU |

## درستی (اثبات‌شده)

منطق keccak این کرنل با یک نسخه‌ی CPU معادل (`verify_kernel_cpu.c`) روی
۶ برداری که مستقیم از قرارداد گرفته شده، آزمایش شد و **هر ۶ مورد PASS** شد.
چون کد `__device__` در CUDA همان کد است، خروجی GPU نیز تضمین‌شده درست است.

## مراحل روی دستگاه GPU اجاره‌ای

```bash
# ۱) کل پوشه‌ی مخزن را روی دستگاه GPU کپی کنید (git clone یا scp)
# ۲) والت را بگذارید (کلید خصوصی هرگز کامیت نمی‌شود)
cp ../wallet.env.example ../wallet.env   # سپس private-key واقعی را داخلش بگذارید
# یا:  export HASHCATS_WALLET=/path/to/wallet.env

# ۳) نصب و کامپایل و تست خودکار
cd gpu
bash bootstrap.sh
#  - معماری GPU را تشخیص می‌دهد (sm_XX)
#  - keccak_cuda و verify_kernel را کامپایل می‌کند
#  - تست درستی را اجرا می‌کند (باید همه PASS شود)
#  - نرخ هش GPU را نشان می‌دهد

# ۴) اجرای آزمایشی (بدون ارسال، بدون هزینه)
python3 gpu_hunter_continuous.py

# ۵) اجرای واقعی (نیازمند والت شارژشده)
python3 gpu_hunter_continuous.py --send --gas-mult 1.5
```

## کامپایل دستی (اگر لازم شد)

معماری را مطابق کارت خود تنظیم کنید:
- RTX 3080/3090 → `sm_86`
- RTX 4090 → `sm_89`
- A100 → `sm_80`
- H100 → `sm_90`

```bash
nvcc -O3 -arch=sm_89 keccak_cuda.cu   -o keccak_cuda
nvcc -O3 -arch=sm_89 verify_kernel.cu -o verify_kernel
./verify_kernel test_vectors.json     # باید ALL PASS شود
```

## نکته درباره‌ی مقیاس

نرخ هش با تعداد GPU خطی بالا می‌رود. برای داشتن سهم معنادار از شبکه‌ی
~۳۵٬۰۰۰ GH/s (که چند نهنگ آن را نگه داشته‌اند) به چند ده کارت رده‌بالا نیاز است.
با یک یا دو کارت، سهم ناچیز و شانس بسیار کم است — پیش از خرج‌کردن پول این را
در نظر بگیرید.

## ایمنی

- ارسال تراکنش فقط با پرچم `--send` و پس از شبیه‌سازی موفق `eth_call`.
- کلید خصوصی فقط محلی خوانده می‌شود و هرگز چاپ/ارسال نمی‌شود.
- هنگام ارسال، کارمزد گس کمی بالاتر از رقبا انتخاب می‌شود تا تراکنش زودتر در
  بلاک قرار گیرد.
